Dental Malocclusion Detection & Teeth Alignment Analysis

Jul 2025 – Sep 2025
Individual project
View code →

A YOLOv9-based pipeline that detects malocclusion and analyzes teeth alignment directly from dental X-rays, built to support faster orthodontic screening.

  • Reached ~97% detection accuracy across a 13,000+ image dataset.
  • Used Grad-CAM to visualize exactly which regions drove each prediction, so the output stays interpretable for clinical review.
  • Shipped as an interactive Gradio app for real-time image upload and prediction.
PythonYOLOv9Grad-CAMGradioOpenCV

Problem

Screening for malocclusion from dental X-rays is manual and time-consuming, and it depends heavily on clinician availability.

Approach

Trained a YOLOv9 detector on 13,000+ X-rays to find malocclusion and analyze tooth alignment, then added Grad-CAM so each prediction shows what the model looked at.

Result

~97% detection accuracy, delivered as an upload-and-predict Gradio app that works in real time.

Where it goes next

Report precision, recall and mAP on a held-out set, validate against clinician labels, and test on X-rays from different machines.

  2. YOLOv9 detector
  3. Alignment analysis
  4. Grad-CAM explanation
  5. Gradio app

RL-Driven Autonomous Rover for Hazard Detection & Environmental Exploration

2026
Team project · 3 members
View code → Play with a mini version →

A simulated rover that learns to navigate a disaster-hit area and map the full space — with no hazard map handed to it in advance. Hazards are discovered through perception, not given as ground truth.

  • Tabular Q-learning over a discretized grid, paired with a lightweight CNN hazard classifier trained on synthetic imagery.
  • Ran a 4-way reward ablation (baseline / coverage / curiosity / full risk-aware) to confirm the coverage-vs-safety trade-off the team was targeting.
  • Built a step-by-step visual demo of the rover scanning cells, updating its hazard map, and choosing its next move.
PythonReinforcement LearningQ-LearningCNN

Problem

After a disaster there is no hazard map. A rover has to cover the area and stay safe while discovering hazards on its own.

Approach

Tabular Q-learning on a discretized grid, plus a lightweight CNN that classifies hazards from synthetic imagery. Hazards are perceived, never given as ground truth.

Result

A 4-way reward ablation (baseline, coverage, curiosity, risk-aware) confirmed the coverage-vs-safety trade-off, plus a step-by-step visual demo.

Where it goes next

Swap synthetic imagery for real camera data, move beyond tabular methods for larger maps, and test on physical hardware.

Pipeline
  1. Grid environment
  2. CNN hazard classifier
  3. Hazard map update
  4. Q-learning policy
  5. Next move

PythonIDSThreat ModelingRisk Analysis

IoT-Enabled Smart Walker for Fall Risk Prediction

Patent — filing in progress
Co-inventor · team project
View code → Try the risk simulator →

An Arduino-based walker for elderly mobility support that predicts fall risk before it happens, using dual IMUs and load cells with sensor fusion. Full details in the patent section.

ArduinoMPU6050HX711Sensor fusion

Problem

Most walkers only react after a fall. Older adults need an early warning that stability is getting worse.

Approach

Dual MPU6050 IMUs and dual HX711 load cells feed a sensor-fusion Fall Risk Prediction engine and a Dynamic Stability Reserve score. It runs standalone on Arduino with no cloud or phone.

Result

Inventive disclosure filed with IIPRD; patent filing in progress. Estimated hardware cost under USD 30.

Where it goes next

Field testing with real users and calibrating risk thresholds against measured data.

Signal flow
  1. IMUs + load cells + obstacle sensing
  2. Sensor fusion
  3. Fall Risk Prediction
  4. Dynamic Stability Reserve
  5. Adaptive assistance
